# הזדהות וניהול משתמשים — מה שנשאר לעשות ידנית

הקוד מוכן. שלושת השלבים נעשים פעם אחת.

## 1. להפעיל התחברות בפרויקט
Firebase Console → Authentication → Sign-in method → **Email/Password** → Enable.
(ההתחברות באפליקציה היא בטלפון וסיסמה; הטלפון מומר מאחורי הקלעים לכתובת פנימית.)

## 2. לפרוס את הפונקציות
```
firebase deploy --only functions
```

## 3. ליצור את המשתמשים
במסך "👥 משתמשים" אצל המנהל — להזין לכל אחד שם, טלפון וסיסמה.
המשתמש הראשון שנוצר חייב להיות המנהל.

## 4. רק בסוף — להדק את ההרשאות
לאחר שכולם נוצרו והתחברו בהצלחה:
```
cp firestore.rules.new firestore.rules
firebase deploy --only firestore:rules
```
מרגע זה חשבון הפחח נוגע רק בנתוני הפחחות, ומסמך הסיסמאות נגיש למנהל בלבד.

## חשוב
- אין להעלות סיסמאות לקוד או לגיט. הן נשמרות רק במסד, במסמך שרק המנהל קורא.
- שינוי סיסמה מנתק את המשתמש מכל המכשירים — זו הדרך להוציא מישהו.
- עד שההרשאות מהודקות, אין לשמור סיסמאות אמיתיות במסך הסיסמאות.
