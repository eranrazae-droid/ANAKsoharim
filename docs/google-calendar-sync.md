# סנכרון יומן גוגל — מה שנשאר לעשות ידנית

הקוד מוכן ב-`functions/index.js`. ארבעת השלבים הבאים נעשים פעם אחת בלבד.

## 1. להפעיל את Google Calendar API
בקונסולה של גוגל קלאוד, בפרויקט `anak-soharim`:
APIs & Services → Library → **Google Calendar API** → Enable

## 2. למצוא את כתובת המייל של חשבון השירות
IAM & Admin → Service Accounts.
הכתובת נראית כך: `anak-soharim@appspot.gserviceaccount.com`

## 3. לשתף את היומן עם הכתובת הזו
ביומן גוגל → הגדרות היומן → שיתוף עם אנשים →
להוסיף את כתובת חשבון השירות עם הרשאת **"עריכת אירועים"**.

## 4. לרשום את היומן ולהפעיל
במסד הנתונים, במסמך `config/google_calendar`, לשמור:

```
calendarId: "primary"     ← או כתובת היומן הספציפי
```

ואז לפרוס את הפונקציות פעם אחת:

```
firebase deploy --only functions
```

ולבסוף לפתוח בדפדפן פעם אחת:

```
https://europe-west1-anak-soharim.cloudfunctions.net/startCalendarSync
```

התשובה מחזירה `ok: true` ואת מספר האירועים שנקראו. מכאן הסנכרון עובד לבד.

## מה קורה מאחורי הקלעים
- **מהאפליקציה לגוגל** — כל שמירה/עריכה/מחיקה ב-`calendar_events` נכתבת מיד ליומן.
- **מגוגל לאפליקציה** — גוגל שולח התראה לפונקציה `calendarPush` בכל שינוי, והיא מושכת רק את מה שהשתנה.
- **מניעת לולאה** — כל אירוע ביומן גוגל נושא את מזהה המסמך שלנו, ואירוע שנכתב אצלנו מגוגל מסומן ולא נשלח בחזרה.
- **חידוש** — ההרשמה אצל גוגל פגה כל 30 יום; `renewCalendarWatch` רצה כל לילה, מחדשת אותה, וגם מושכת שינויים כגיבוי אם התראה כלשהי לא הגיעה.

## אם משהו לא עובד
- אין אירועים שעוברים → לבדוק ששיתפת את היומן עם חשבון השירות בהרשאת עריכה.
- אירועים עוברים לגוגל אבל לא חוזרים → להריץ שוב את `startCalendarSync`.
- הכל נעצר אחרי חודש → לוודא ש-`renewCalendarWatch` רצה (Cloud Scheduler).
