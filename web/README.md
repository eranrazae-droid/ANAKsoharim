## ⚠️ מתג העלייה לאוויר

כל עוד `NEXT_PUBLIC_SITE_LIVE` אינו מוגדר, האתר **חסום לחלוטין מגוגל**:

- `robots.txt` מחזיר `Disallow: /`
- כל עמוד נושא `<meta name="robots" content="noindex, nofollow">`

זה מונע מאתר ההכנה להתחרות באתר הישן בגוגל.

**ביום המעבר בלבד:** להגדיר ב-Vercel את משתנה הסביבה

```
NEXT_PUBLIC_SITE_LIVE=true
```

ולהריץ פריסה מחדש. זו הפעולה היחידה שפותחת את האתר לגוגל.

## מה עוד חסר לפני עלייה לאוויר

- ⬜ **טפסי לידים לא מחוברים** — מציגים "תודה" ולא שולחים כלום
- ⬜ **תוכן ההמלצות** — להעתיק מהאתר הישן אל `app/reviews-data.ts`
- ⬜ **טבלת `carcode` → מספר רישוי** להפניית עמודי הרכב הוותיקים
- ⬜ **השלמת ההפניות** מייצוא Search Console
- ⬜ **מדור מאמרים** להחלפת `/articles.asp`
- ⬜ **תמונות** — מעבר ל-`next/image` לשיפור מהירות
- ⬜ **גופן עברי** — כרגע Geist בלטינית בלבד, העברית נופלת לגופן מערכת

## צ׳קליסט יום המעבר

1. חיבור הדומיין `www.03-5189189.co.il` ל-Vercel
2. הפניית הגרסה בלי `www` אל `www`
3. **סגירת `ftp.03-5189189.co.il`** — מגיש היום את האתר המלא ומאונדקס בגוגל
4. הגדרת `NEXT_PUBLIC_SITE_LIVE=true` ופריסה מחדש
5. בדיקה ש-`/robots.txt` כבר לא חוסם
6. בדיקה שאין `noindex` באף עמוד
7. בדיקה ידנית של 20-30 הפניות מהעמודים החשובים
8. שליחת `sitemap.xml` ב-Search Console
9. חיבור Search Console ו-Analytics לאתר החדש
10. גיבוי מלא של האתר הישן לפני כיבוי
11. מעקב אחר שגיאות 404 ב-Search Console — שבועיים ברצף
12. אין שינויים נוספים באתר במשך 4-8 שבועות
