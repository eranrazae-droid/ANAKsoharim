# סרטוני האתר

מעלים לכאן קובץ mp4 ורושמים את הנתיב ב-`app/site-config.ts`, בשדה
`VIDEO.file` — למשל `/video/anak.mp4`.

עדיף להעלות ליוטיוב ולהשתמש ב-`VIDEO.youtubeId`: זה לא עולה תעבורה,
נטען מהר יותר בכל העולם, והסרטון נמצא גם בחיפוש ביוטיוב עצמו.

בכל מקרה הסרטון נטען רק כשלוחצים עליו, כדי שלא יאט את האתר.
