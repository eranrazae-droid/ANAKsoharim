# עיצוב אחיד לכל מסכי הטלפון

העיצוב ב־`ops/css/ui2m.css`. לא שונו JavaScript, לוגיקה, מזהים, שדות, טקסטים, הרשאות או פעולות. עיצוב המחשב ותמונת הבית נשמרו. עודכנה גרסה ל־581 ב־`index.html` וב־service worker.

## מה השתנה

- פלטת ירוק, מרווה וזהב של בית הטלפון בכל הכותרות, השדות, הכרטיסים, הלשוניות, כפתורי הפעולה והחלוניות.
- התאמות ייעודיות לרכיבי הפחחות, שטיפה, בורות, קליטות, איסוף, משימות וארון המצברים; תמונות הרכב, לוחיות הרישוי וצבעי סטטוסים נשמרו.
- מסכי מלאי, סידור מגרש, ריקול, טעינה, מצברים, נסיעות מבחן, בעלויות, רענון, חלקים, הגדרות ויומן משתמשים באותה שפה.
- מטרות מגע של לפחות 44px בכפתורים ובשדות, שדות טקסט בגודל 16px, ומיקוד מקלדת ברור.
- סרגלי הוספה ושליחה וחלוניות מותאמות נשארים מעל הניווט התחתון. טבלאות/גרפים רחבים נגללים בתוכם.
- כרטיס פרטי הרכב בצ׳אט, שהיה לא תחום ב-CSS הקודם, תחום כעת גם הוא ל־`body.ui2m` ולרוחב עד 900px.
