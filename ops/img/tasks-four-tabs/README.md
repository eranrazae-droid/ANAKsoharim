# לוח המשימות בטלפון — החלוקה שאושרה

סדר הלשוניות מימין לשמאל:

1. דחיפות גבוהה: משימות בעדיפות עליונה, משימות ללקוחות ומוסך, מוסך.
2. כללי: משימות כלליות.
3. בעלי מקצוע: חביב, ולאדי, רפד, זגג.
4. נהגים: גיל, עופר, איתי.

כל קטגוריה מוצגת תחת חוצץ עם מספר המשימות הפתוחות; משימות שהושלמו נגישות בסעיף סגור באותה קטגוריה. לשוניות העל מציגות מונה פתוחות. נשמרה הרשימה הצפופה שאושרה, ללא כרטיסים גדולים.

נתונים קיימים אינם נעלמים: רדארים מופיע אצל בעלי מקצוע רק אם יש לו משימות; תוויות שאינן ברשימה נגישות כקבוצות נוספות בכללי. אין שינוי בערכי התוויות במסד.

קבצים: `ops/js/ui2m-tasks.js` (קובץ תצוגה קיים וטעון כבר), `ops/css/ui2m.css`. השכבה משתמשת ב־`_tkRow` וב־`_tkRowsDrag` הקיימים, כולל פעולות השלמה, עריכה, מחיקה, החלקה וגרירה בתוך אותה קטגוריה. אין שינוי בקובצי `ops/js/app/` או במזהים/נתונים. השינוי חל רק על מנהל בטלפון עם `ui2m`. נהגים, איברהים ומחשב ממשיכים בתצוגה הקיימת שלהם.

בדיקות: תחביר JS; בניית הדמו; git diff --check. בדיקת DOM מדומה אימתה את סדר ארבע הלשוניות, שייכות כל קטגוריה, מונים, גישה לתוויות נוספות ולהושלמו, שימוש בפונקציות השורה והגרירה הקיימות, וחוסר הפעלה אצל נהג/פחח/מחשב/מתג כבוי. בדיקות אלה אינן בדיקת דפדפן או בדיקת שמירה לשרת.

לפני מיזוג — קלוד:

- לעדכן גרסה פנויה ב־`ops/sw.js` ובכל הפניות המשאבים ב־`ops/index.html` (בסיס הבקשה v614). קובץ ui2m-tasks.js כבר מחובר ולכן אין צורך בחיבור חדש.
- לבדוק בדמו בטלפון 360/390/430/768/900px: ארבע הלשוניות, מונים וחוצצים, כותרות ארוכות, החלפת משתמש, מעבר 900/901 ומתג עיצוב כבוי.
- לבדוק השלמה, עריכה, החלקה למחיקה וביטולה, גרירה בתוך קטגוריה, עדכון בזמן אמת והרחבת הושלמו. לבדוק שאין שינויים במסך איברהים ובמחשב.
- להשלים צילומי לפני/אחרי ובדיקה חזותית. הסביבה כאן אינה כוללת דפדפן והורדת Chromium נכשלה; אין לציין שהאימות החזותי הושלם.

קובצי השחרור אינם חלק מהבקשה המצומצמת: העלאת index.html המלא נחסמה בבדיקת האישור האוטומטית במשימה הקודמת, ולכן נכללים כאן קובצי התצוגה בלבד. לא בוצעו מיזוג או פרסום.
