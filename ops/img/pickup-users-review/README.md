# עיצוב הילה ומשה בטלפון ובמחשב

הגורם: שכבת הצבעים בטלפון הכירה pickup_agent ו־pickup_driver, אך מסך הבית החדש הכיר רק manager ו־driver. מעטפת המחשב הוגבלה למנהל. לכן שני משתמשי האיסוף נשארו בבית הקודם.

התיקון מחבר את שני תפקידי האיסוף לבית החדש עם תמונת הכותרת, ירוק/מרווה/זהב, קוביות ומונים. בטלפון יש ניווט תחתון ובמחשב תפריט צד. ניתן לחזור לבית, לפתוח התראות, לפנות למנהל ולצאת מהמשתמש. חלוניות האיסוף של הילה מקבלות גם הן את השפה החדשה.

משה: איסוף רכבים, פחחות, שטיפה והצעת משימה, דרך כפתורי המקור. הילה: כפתור איסופים והרכבים שכבר מוצגים ברשימה הקיימת שלה בלבד. הנתונים והמונים נקראים מתצוגת המקור. לא נוספו שאילתות, מקורות נתונים או הרשאות. לא מתווסף להם צ׳אט AI. איברהים אינו זכאי לשכבה החדשה, ומעטפת המנהל במחשב ממשיכה לפעול בנפרד.

קבצים: ops/js/ui2-mobile.js, ops/css/ui2m.css, ops/css/ui2-pickup.css. קובץ המחשב החדש נטען משכבת התצוגה הקיימת רק במחשב של משתמש איסוף, ונושא את גרסת הסקריפט. הוא מעתיק את שפת מסכי ui2-system תחת מחלקה ייעודית u2pickup-desktop, ללא הפעלת ניווט המנהל. לא שונו קובצי הלוגיקה העסקית, מזהים או פעולות מקור.

בדיקות שעברו: node --check, בניית הדמו, git diff --check. בדיקת renderer מדומה אימתה זכאות לשני תפקידי האיסוף ברוחב 390/900/901/1440, תפריט משה, איסופים בלבד אצל הילה, עדכון מונים, מניעת לולאת ציור, בידוד איברהים, שמירת מעטפת המנהל וכיבוד העדפת עיצוב ישן במחשב.

נדרש לפני מיזוג ושחרור:

- קלוד יעדכן מספר גרסה פנוי ב־ops/sw.js ובכל הפניות ops/index.html (בסיס הבקשה v621). אין צורך בשורת טעינה חדשה: ui2-mobile.js ו־ui2m.css כבר טעונים, וקובץ המחשב הנוסף נטען בעת הצורך.
- לבדוק בדמו ובמכשיר אמיתי את שני המשתמשים ב־360/390/768/900/901/1280/1440: בית, ניווט, עדכון חי, פתיחת רשימת איסופים, פרטי רכב, ניווט לכתובת, מסמך וסימון איסוף דרך הפעולות הקיימות. אצל משה גם פחחות, שטיפה והצעת משימה. לא נבדקו פעולות מול נתוני ייצור.
- לבדוק מעבר הלוך וחזור בין מנהל/משה/הילה/איברהים, שינוי רוחב, חזרה לבית, יציאה וטיוטה פתוחה. להפיק צילומי לפני/אחרי.
- דפדפן מקומי אינו זמין כאן והורדת Chromium נכשלה בסבב הקודם. אין בדיקה חזותית מלאה ואין צילומי מסך חדשים; אין להציג אותם כהושלמו.

index.html המלא נחסם בעבר בבדיקת האישור האוטומטית, ולכן בקשה זו מצומצמת לקובצי התצוגה ועדכון הגרסה נשאר לקלוד. לא בוצעו מיזוג או פרסום.
