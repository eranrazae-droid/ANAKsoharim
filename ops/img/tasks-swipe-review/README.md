# החלקת משימה ימינה למחיקה

בלוח המנהל הצפוף בטלפון, בכל ארבע הלשוניות ובשורות שהושלמו: החלקה ימינה חושפת משמאל כפתור אדום ״מחיקה״. ההחלקה עצמה אינה מוחקת. הכפתור מפעיל את tkSwipeDelete הקיים, עם חלון הביטול הקיים של חמש שניות. לחיצה מאוחרת על השורה, החלקה חזרה או לחיצה בחוץ סוגרות את האפשרות. קליק סינתטי מיד אחרי המחווה נחסם בלי לסגור את הכפתור שנחשף.

קבצים: ops/js/ui2m-tasks.js ו־ops/css/ui2m.css. שינוי תצוגה ומחווה בלבד, בקבצים שכבר נטענים. לא שונו מחיקה, ארכיון, נתונים, הרשאות או קובצי ops/js/app. ההפעלה מוגבלת לשורות u2tasks של מנהל עם ui2m בטלפון. ידית גרירה, כפתור השלמה ופעולות בתוך המשימה אינם מתחילים החלקה; תנועה אנכית נשארת לגלילת המסך. ביטול pointercancel מחזיר את הכרטיס למקום.

עברו בדיקת תחביר JS, בניית הדמו, git diff --check ובדיקת אירועי pointer מדומה: ימינה חושפת; שמאלה אינה פותחת; תנועה אנכית לא פותחת; קליק לאחר ההחלקה לא פותח פרטים/סוגר בטעות; לחיצה מאוחרת סוגרת; ביטול מחווה סוגר; פקדי השורה אינם נתפסים.

לקלוד לפני מיזוג: לעדכן מספר גרסה פנוי ב־ops/sw.js ובכל הפניות ops/index.html (בסיס הבקשה v617). לבדוק בדמו ובטלפון אמיתי את הגלילה, חשיפת המחיקה, לחיצה למחיקה וביטולה בתוך חמש שניות, החלקה חזרה, פתיחת משימה אחרת, גרירה, ומעבר בין הלשוניות. להשלים צילומי לפני/אחרי; בדיקת דפדפן וצילומים לא בוצעו בסביבה זו. אין לטעון שנבדקה מחיקה מול נתוני ייצור. אין שינוי במחשב או באיברהים.

קובצי השחרור נשארים לקלוד: העלאת index.html המלא נחסמה באישור האוטומטי בעבודה הקודמת ולכן בקשה זו כוללת רק את קובצי התצוגה. לא בוצעו מיזוג או פרסום.
