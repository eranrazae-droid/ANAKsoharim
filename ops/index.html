משתמשים וסיסמאות
התפקיד נקבע לפי השם — ליאל מנהל · גיל, עופר, איתי נהגים · משה והילה איסוף · איברהים פחח.
יומן גוגל
לפני ההפעלה, פעם אחת בלבד:
1. להפעיל Google Calendar API בפרויקט
2. לשתף את היומן עם 343573102369-compute@developer.gserviceaccount.com בהרשאת לבצע שינויים ולראות את כל פרטי האירועים
ביומן גוגל: הגדרות היומן → "שילוב היומן" → מזהה היומן. ביומן ראשי זו כתובת המייל של החשבון; ביומן נפרד כתובת שמסתיימת ב-group.calendar.google.com. היומן יכול להיות מכל חשבון גוגל.
🗺️ גוגל מפות

מפתח Google Maps — הכתובות, המרחקים וזמני ההליכה במפת האיסוף יגיעו ישירות מגוגל. יצירת מפתח: console.cloud.google.com ← APIs ← הפעל Geocoding API ו-Directions API ← Credentials ← Create API key.

משחקי ברצלונה

כל שלושה ימים המערכת מושכת מחדש את כל המשחקים הידועים של ברצלונה — ליגה, גביע ואירופה — עם התאריך והשעה המעודכנים בשעון ישראל, ומוסיפה אותם ליומן. משחק שנדחה או ירד מהלוח נמחק מהיומן לבד.
כדי להפעיל צריך מפתח חינמי מ-football-data.org: הרשמה עם מייל ← המפתח מגיע במייל ← להדביק כאן.
